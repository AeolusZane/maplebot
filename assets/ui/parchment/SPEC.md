# 羊皮卷主题素材规格 v1

使用内置 imagegen 生成，原始提示词见 prompts.json。五张 PNG 均为 1254 × 1254 像素，不含文字，保留原始输出；应用不依赖生成目录。

| 文件 | 用途 | 绘制规则 |
| --- | --- | --- |
| paper.png | 主工作区浅羊皮纸 | 原尺寸平铺，不随窗口拉伸 |
| wood.png | 侧栏深胡桃木 | 原尺寸平铺，竖向纹理 |
| panel.png | 卡片及分组雕边纸面 | 九宫格；四边各取源图 80 px，显示边宽 8 逻辑 px |
| button.png | 普通按钮、折叠栏 | 九宫格；四边源图 48 px，显示边宽 3 逻辑 px |
| selected.png | 选中导航、主按钮 | 九宫格；四边源图 48 px，导航边宽 4、按钮边宽 3 逻辑 px |

字体、图标、数值、勾选状态和表格由 Qt 原生绘制。材质高分辨率足以覆盖 100%–200% 常见缩放；边角固定，中心与边缘拉伸。纹理是生成式素材，超大面积重复时仍可能看出平铺边界。

交互状态：普通按钮使用原材质；hover 改变轮廓与文字颜色；pressed 使用深色轮廓并将内容右下偏移 1 px；disabled 去除材质并降低对比。导航选中使用绿皮材质。输入框聚焦使用苔绿轮廓。亮色、暗色主题保持可选；主题保存在 QSettings。

颜色：深棕正文 #493523、次要文字 #806b4e、浅纸面 #f3e8cd、黄铜边线 #b6a07c、苔绿强调 #687b45。图表与诊断输出同步使用主题色。

实现入口：src/ui/parchment.py；共用色板：src/ui/theme.py。

风格选择保留原有亮色、暗色和羊皮卷，羊皮卷下使用三张可点击缩略图，绿色边框标识当前选择。所有识别结果来自现有回调，装饰不会生成或替换业务数据。

## 第三版：运行时轻量素材与统一侧栏（当前实现）

三种主题现在统一使用 `themeSelector` 下拉框，不再使用主题缩略图或底部风景。原始生成文件保留供设计迭代，应用只加载 `runtime/`：

- 图标 96 px，角色徽章 192 px，纸面与九宫格材质 627 px，支持常用高 DPI 显示。
- 材质源切片数值减半，逻辑显示边宽保持不变，避免缩图改变边框比例。
- 用 `tools/build_parchment_assets.py` 从原图生成；尺寸、文件体积和解码像素内存记录在 `runtime/manifest.json`。
- 运行时文件合计 3,018,807 字节，原图合计 24,685,011 字节；对应像素解码内存从 75,480,768 降到 8,231,220 字节。这是素材开销，不是应用整体内存测量。
- 图标和缩放后的 QPixmap 使用有界缓存；角色徽标仅在内容变化时更新。
- 品牌区取消深色矩形背景，固定图标占位并缩小品牌文字，保留明确间距；侧栏分隔线减为 1 px。
