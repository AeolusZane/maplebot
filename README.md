# 行为生成与检测评测实验项目

状态：方案文档已编写，程序尚未实现，Windows 实机验证尚未进行。

目标：建立可复现的行为生成、真人操作采集、回放和检测评测系统。首版采用环境条件驱动的半马尔可夫策略，优先 CPU、本地闭环；Windows 负责采集和实测，Mac 可开发与运行离线测试。

本目录可以整体复制为新代码库的初始内容。文档使用相对链接，不依赖当前 Mac 路径。不要把研究目录中的完整第三方仓库或真人数据直接一起提交。

## 用户需要准备

- 创建新代码库，复制本目录；远程仓库创建和推送由用户另行执行。
- Windows 测试机：记录 Windows 版本、CPU、内存、GPU/显存、显示缩放、分辨率和目标程序版本。
- 选定一个固定地图、角色/职业、技能配置；在运行清单中填写，不需要阻塞 Mac 上的核心开发。
- Phase 2 完成后，正常操作录制几段短样本并检查质量；采集流程通过后再扩大样本。
- 回看少量典型片段，为停顿、放弃目标和恢复等行为补充意图标签。
- Windows 每阶段产出报告和脱敏诊断信息；原始视频默认留在本机。

## 完成定义

核心交付为 Phase 1–6，通过 Windows 回放、采集、模拟执行和实验报告验证。局域网是可选扩展，不影响本地版本验收。没有真人数据时，可以交付技术闭环，但结论必须写为“拟真程度未验证”；没有足够真人负样本时，不能声称达到低误报检测指标。
