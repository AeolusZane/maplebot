# Phase 2：Windows 真人采集与回放

上级：[requirements](../requirements.md)。依赖：Phase 1。落实 R04–R06、R13。

## 实现

- 目标窗口选择、允许键集合、显式录制提示与停止入口。
- 同机单调时钟记录输入与实际抓帧时间；独立视频帧索引。
- 落实 R15：同步保存推理时同口径的 Observation、地图版本、识别完成时间、held_keys 和近期输入；未知字段不以人工真值补齐。
- 提供因果样本对齐检查：先按 session 划分，再切历史窗口，保留按下边沿、持续时间和删失标记；任何未来观察和动作不得进入输入特征。
- 失焦停止采集目标输入，闭合本地记录状态并标记取消原因；恢复后不得伪造新的 keydown。
- 有界异步写入、磁盘检查、异常会话恢复与 quality 报告。
- 简易回放时间轴与区间标签，原始记录只读。
- 创建可视输入反馈测试窗口，供同步与按键闭合验证。

## 用户参与

先完成测试窗口录制，再录固定场景的 3 段 10–15 分钟试采集；回看典型片段并标记 unknown/明确意图。视频与输入默认本地保存。

## 验收

- [ ] 测试窗口的已知按键序列无静默漏记，repeat 与按下事件分离。
- [ ] 切到其他应用后不记录其输入；停止、异常时标记未闭合事件。
- [ ] 视频可按事件时间定位，报告实测同步误差；建议初始 p95≤50ms，超标样本不做精细时延拟合。
- [ ] 磁盘不足、队列满、捕获失败有可见结果。
- [ ] validate-session 与 replay 可用，标注不覆盖原始数据。

证据：合成序列检查、同步测量、试采集 quality。未通过质量门槛不扩大采集。

## v0.3 录制集成与验收（R17、R18）

沿用原 UI、截图与定位，新增 manual_record 入口；F4 地图路线继续单独保存。演示必须记录原始按下/释放与在线观察，不从路线 PNG 生成真人标签。采集前关闭按键、Buff、拾取、药水、自动登录点击、回城等全部自动输出，不以旧 disable_control 代替完整门禁。

验收：F4 资源仍可供 legacy 使用；manual_record 不初始化 Interception 输出，输出 spy 全程计数为零；切换焦点与结束正确闭合或标记输入区间。
