# Phase 4：条件半马尔可夫生成器

上级：[requirements](../requirements.md)。依赖：Phase 3。落实 R03、R09。

## 实现

- 实现 PATROL/APPROACH/ATTACK/RECOVER/IDLE，状态持有进入时间、目标和预计期限。
- 实现状态可用条件、环境条件转移、驻留采样、完成条件与硬中断。
- 用少量版本化 profile 表示参数集合；人工参数明确标记 synthetic。
- 每次选择记录候选集合、选择结果、reason_code、种子与策略版本。
- 高层意图交给导航；不在状态停留期内忽略新观察。

## 验收

- [ ] 不可达目标、目标消失、定位失效、恢复超时均有明确出口。
- [ ] 驻留不会因每帧调用被重新采样；不同 FPS 的虚拟时钟场景给出相同时间语义。
- [ ] 固定输入和 seed 可重放，不同 seed 的采样有变化且均满足约束。
- [ ] 完成 B0/B1/G 配对模拟，输出工程有效性和行为差异，不把差异直接判为拟真。
- [ ] profile 切换需要显式 reset/epoch 更新，不在中途隐式改变身份参数。

证据：状态转移覆盖、边界测试、模拟报告。范围外：HSMM 隐状态训练、深度学习、远端服务。
