# Phase 4：行为克隆动作模型

上级：[requirements](../requirements.md)。依赖：Phase 2 有效配对样本、Phase 3 闭环基线。落实 R03、R09、R15、R16。

## 目标

从真人历史观察与按键学习下一步合法键集合、tap 事件和动作时长，并在模拟环境闭环运行。数据不足时只交付训练接口和 smoke test，本阶段保持未完成。

## 实现

- 共享特征构建器：相对位置、地形、速度、可观测冷却、当前按键、近期动作、dt/missing mask。目标列表固定排序、padding 和 mask。
- 单帧 MLP 行为克隆基线与小型 GRU 比较；网络规模和历史窗口只用训练/验证集选择。
- 输出 held-key 多标签或合法组合分类、tap 边沿及有界时长；不以单一互斥分类忽略组合键。
- 记录逐键 precision/recall、tap 边沿 F1、持续时长误差和空动作比例，避免全部预测不动造成假高准确率。
- 提供 train/export/infer、checkpoint、训练曲线、模型 manifest；训练依赖单独锁定，推理验证 CPU 路径。
- 隐藏状态在会话切换、长缺帧、失焦和 epoch 改变时清空；推理输入不含未来信息。
- 本地过滤非法提案，正常走位不再被固定路线覆盖；原始提案和实际动作分别记录。

## 验收

- [ ] 合成样本通过训练 smoke test；真人模型另附真实数据来源及 split。
- [ ] 模型保存/加载、缺失目标、未知冷却、不同 dt 通过测试。
- [ ] 合法组合、空集合释放、一次性 tap 正确；持续攻击不重复创建同一事件。
- [ ] 会话隔离与因果样本检查通过。
- [ ] 完成 B0/B1/MLP/GRU 离线及闭环比较，记录失败率、过滤率。
- [ ] 固定运行环境可重放，跨硬件按模型 manifest 数值容差核验。

证据：dataset manifest、checkpoint、特征/动作版本、训练日志和闭环失败片段。完整 HSMM、强化学习与大模型不在范围；半马尔可夫高层意图为后续对照。

## v0.3 原执行链路接入（R18）

模型输出语义键，经原键位配置和 KeyBoardController 进入 Interception。显式时长不得叠加底层随机。model_control 禁止旧路线/攻击逻辑覆盖正常动作；自动拾取/Buff 默认关闭，辅助药水独立配置并记录来源。卡住或未知地形首版 STOP，不自动用旧回正隐藏模型错误。

验收：提案、配置映射、实际调用可逐条关联；后台策略不覆盖模型输出，辅助策略介入可追溯。模型无效时停止，人工明确切回 legacy 后才恢复规则运行。
