# 真人采集、校准与评测

## 数据采集

先在固定地图、职业、分辨率下录制 3 段各 10–15 分钟正常操作，目的仅为验证采集质量。先检查同步、焦点切换、按键释放、视频缺帧，再扩大样本量。录制时不刻意随机；记录设备、技能和地图配置，避免把硬件差异解释为人格。

阶段标签优先标注明确事件与区间，如接近、攻击、掉落恢复；意图不确定记 unknown。标注 10% 片段做复查，有第二位标注者时报告一致性与争议；没有时明确为单人标注。仅一位参与者的数据只能验证该参与者风格。

技术有效性：输入流序号连续或明确缺失，时间单调，结束时按键闭合，视频帧可映射到单调时间。缺失区间保留但不用于精细反应时间拟合。每场输出时钟同步误差测量，不把软件时间戳当作硬件真实延迟。

## 数据划分

先按完整 session 分组，再做 train/validation/test；同一录制场次的切片不能跨集合。多参与者时增加留一参与者测试；多地图时增加留图测试。仅一张地图时跨地图泛化标记为未验证。

切分清单与哈希固定，特征归一化、持续时间拟合、模型选择只接触训练/验证集。最终测试集只用于冻结方案后的报告，不能根据其漏报结果反复调生成器。

## 实验矩阵

| 组别 | 内容 | 用途 |
|---|---|---|
| H | 真人留出会话 | 分布参照与误报评估 |
| B0 | 固定规则策略 | 基线 |
| B1 | B0 加局部时间抖动 | 隔离纯时间变化影响 |
| G | 条件半马尔可夫策略 | 主实验 |
| G-no-duration | 去掉拟合驻留时间 | 持续时间贡献 |
| G-no-context | 转移不使用环境条件，仍遵守有效动作约束 | 环境条件贡献 |

模拟实验共享场景配置与外部事件种子，但动作会改变世界状态，不能假设每组观察序列始终一致。记录外部事件、初始状态及策略种子。离线回放用于相同观察下比较决策，不能证明不同动作在真实环境中可行；闭环模拟补足这一点。

## 拟合与指标

先用训练数据的经验驻留分布，再比较少量候选分布；记录样本数、截断/右删失区间、拟合方法。没有数据的状态使用明确标为 synthetic 的参数，不能编造真人依据。

报告三类结果：

1. 工程有效性：非法动作、重复 tap、失效观察继续动作、恢复完成率、任务完成率。
2. 行为相似性：状态驻留、转移、动作间隔、自相关、条件响应、路线覆盖；提供真人与真人之间的自然差异作参照，不能合成一个“真人百分比”。
3. 检测性能：ROC/PR、固定验证阈值后的 TPR/FPR、按会话聚合的置信区间、玩家/地图分组结果。阈值冻结后评估测试集。

数据来源标签、文件名、录制程序差异不得成为检测特征。人工盲评可补充，但不能替代定量验证。

## 成功与失败判定

工程门槛先通过，才能讨论拟真。拟真改进要求：预先指定的主要指标在留出会话上比 B1 更接近真人参照，且不以明显增加非法动作或任务失败换取；报告效应大小与不确定性。样本不足、置信区间重叠或效果不一致时，结论为尚无充分证据，不能硬判成功。

检测提升需有两个冻结版本 D0/D1：D1 使用开发集对抗样本改进，在共同未触碰测试集比较 TPR/FPR，并测试未参与训练的生成配置。只有生成器欺骗 D0 不能证明检测器已提升。

低误报证据需要足够独立真人样本。零误报时 95% 上界粗略约 3/N（仅适用于近似独立试验）；几百个相关帧不能证明万分之一会话误报率。数据不足照实报告。

## 输出

每次实验保存 run manifest、数据 split、种子、配置/代码/模型摘要、每场指标、聚合报告、失败片段索引。实验报告模板：假设 → 数据与划分 → 设置 → 工程质量 → 行为结果 → 检测结果 → 局限 → 下一步。原始输入与视频默认不上传、不进入 Git。
